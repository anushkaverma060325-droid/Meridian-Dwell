# Meridian-Dwell
MERIDIAN DWELL is an AI-powered interior design platform that transforms ordinary rooms into personalized living spaces based on individual styles, preferences, and budgets. It combines AI visualization, smart recommendations, and budget-friendly shopping to make interior designing more accessible and effortless.
